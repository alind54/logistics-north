# UX Principles (Executive-Ready)

- Clean, calm layout; avoid noisy gradients/effects.
- Strong information hierarchy:
  - Board for operations
  - List + filters for management
  - Dashboard for executive summary
- Fast search and filtering.
- Clear status and due date visibility.
- Mobile-friendly: collapsible sidebar, sticky filters, large tap targets.
- Accessibility: keyboard support, readable contrast, focus states.
