# Component Guide

## Design tokens
- Use Tailwind defaults with a restrained palette.
- Avoid trendy effects; keep enterprise feel.

## Reusable components
- `DataTable` with server-side pagination
- `FilterBar` (chips + dropdowns)
- `KanbanBoard`, `KanbanColumn`, `KanbanCard`
- `RequestForm` (create/edit)
- `AttachmentUploader`
- `StageTimeline`
- `AuditEventList`

## Mobile patterns
- Board becomes horizontal scroll columns or a stage dropdown + list view.
- Filters in a bottom sheet/drawer.
