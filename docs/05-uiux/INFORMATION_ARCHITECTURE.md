# Information Architecture

## Top-level navigation
- Board
- Requests
- Dashboard
- Admin (role-gated)
- Profile/Settings

## Board screen
- Stage columns (configurable)
- Cards show: title/description snippet, priority, due date, tags, attachment badge, time-in-stage
- Drag/drop + “Move” menu for mobile

## Request detail
- Full description + notes
- Attachments
- Stage timeline (history)
- Audit log
- Edit actions (role-gated)

## Dashboard
- Overdue count
- Aging by stage
- Average time-in-stage
- Priority distribution
