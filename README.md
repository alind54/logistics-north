# Request Tracker (Production-Ready)

This repository is designed to be implemented with **Claude Code in VS Code** using the reference documentation in `/docs`.

## Quick start (after Claude scaffolds the app)
1. Install dependencies
2. Configure environment variables (see `.env.example`)
3. Run database migrations
4. Start dev server

> **Important:** Claude must follow the rules in `docs/06-claude/CLAUDE_INSTRUCTIONS.md`.
